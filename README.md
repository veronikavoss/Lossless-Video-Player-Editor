# Lossless Video Player Editor (무손실 비디오 재생 및 편집기)

![GUI](https://img.shields.io/badge/GUI-PySide6-brightgreen) ![Player](https://img.shields.io/badge/Player-libmpv-orange) ![Backend](https://img.shields.io/badge/Backend-FFmpeg-blue) ![Language](https://img.shields.io/badge/Language-Python%203.10+-yellow)

**Lossless Video Player Editor**는 비디오 파일(MKV, MP4, AVI, WebM 등)을 재인코딩(Re-encoding) 없이 **원본 화질과 음질을 100% 그대로 유지하면서 초고속으로 재생, 정밀 탐색, 구간 자르기, 트랙 분리 및 병합**할 수 있는 데스크톱 미디어 소프트웨어입니다.

초고성능 미디어 렌더링 엔진인 **libmpv**(`python-mpv`)를 기반으로 부드러운 프레임 렌더링을 제공하며, **FFmpeg / ffprobe** 백엔드의 무손실 스트림 복사(`-c copy`) 기술을 통해 대용량 동영상도 수 초 만에 손실 없이 편집합니다.

---

## 🚀 주요 기능

### 1. 초고속 무손실 컷팅 & 추출 (`-c copy`)
- 비디오와 오디오를 다시 인코딩하지 않고 압축된 원본 패킷 스트림을 그대로 복사하므로, **화질/음질 손실이 전혀 없으며** 수 초 만에 작업이 완료됩니다.

### 2. 다중 구간(Multi-Segment) 지정 및 개별 / 병합 출력
- 하나의 영상에서 여러 개의 시작점(`[`)과 끝점(`]`) 구간을 누적해서 지정할 수 있습니다.
- **다중 구간 병합 체크박스 선택 시**: 지정된 여러 구간을 순서대로 이어붙인 **하나의 완성본 파일(`_merged.mkv`)**로 결합 출력합니다.
- **다중 구간 병합 체크박스 해제 시**: 지정된 각 구간을 **개별 분할 클립(`_part1.mkv`, `_part2.mkv` ...)**으로 일괄 분리 저장합니다.
- **선택 영역 반전(Select Inverse)**: 설정한 구간들을 제외한 나머지 영역들을 자동으로 계산하여 자르기 구간으로 반전시킵니다.

### 3. 다중 파일 병합 (Multi-File Merge)
- 서로 다른 영상 파일들을 우측의 **'다중 파일 병합 대기열'**에 드래그 앤 드롭으로 등록할 수 있습니다.
- 대기열 항목의 순서를 위/아래로 이동하거나 더블 클릭하여 개별 영상을 즉시 미리보기 재생할 수 있습니다.
- 하단의 **`[병합 시작]`** 버튼 한 번으로 대기열의 영상들을 순서대로 하나의 파일로 무손실 병합합니다.

### 4. 선택적 트랙(오디오/자막/비디오) 보존 및 자막 추출
- `ffprobe` 메타데이터 연동을 통해 원본 영상에 포함된 모든 비디오, 다국어 오디오, 자막 트랙 목록을 테이블에서 확인합니다.
- 불필요한 음성 언어나 자막 트랙의 체크를 해제하여 **원하는 트랙만 남기고 제거**할 수 있습니다. (구간을 자르지 않고 트랙만 걸러내는 정리 작업도 가능)
- 선택한 자막 트랙을 단독으로 `.srt`, `.ass`, `.vtt`, `.sup`, `.mks` 파일로 손쉽게 추출(Export)할 수 있습니다.

### 5. 무손실 원본 스크린샷 캡처 (`F8`)
- **순수 비디오 프레임 저장**: 자막이나 OSD 그래픽을 배제하고 현재 재생 장면의 **순수 비디오 프레임을 원본 해상도 PNG**로 캡처합니다.
- **파일명 자동 지정**: 영상 파일과 동일한 디렉터리에 `{영상명}_shot_{시-분-초_밀리초}.png` 형식으로 자동 저장되며, 중복 시 카운터가 부여됩니다.
- **클립보드 자동 복사**: 캡처 즉시 운영체제 클립보드에 이미지가 복사되어 메신저, 포토샵, 문서 등에 `Ctrl+V`로 즉각 붙여넣을 수 있습니다.
- **시각적 셔터 피드백**: 캡처 순간 화면이 찰칵하듯 부드럽게 반짝이는 카메라 셔터 플래시 효과를 제공합니다.

### 6. 정밀 미디어 탐색 및 실시간 썸네일 미리보기
- **1프레임 단위 이동 (`D` / `F`)**: 1프레임(약 33ms)씩 정밀하게 이동하여 원하는 키프레임을 정확히 찾아냅니다.
- **5초 단위 쾌속 스킵 (`←` / `→`)**: 넓은 범위를 빠르게 스킵하며 원하는 장면으로 이동합니다.
- **시작점/끝점으로 헤드 점프 (`,` / `.`)**: 등록된 마커 위치로 재생 바를 즉시 이동합니다.
- **유튜브 스타일 썸네일 프리뷰**: 재생 슬라이더에 마우스를 올리면 해당 시간대의 장면을 팝업 툴팁으로 즉각 미리보기(비동기 캐싱)할 수 있습니다.

### 7. 다양한 화면 모드 (최대화 & 보더리스 전체화면)
- **비디오 더블클릭**: 윈도우 창 최대화(Maximized) 및 원래 크기 복원 토글.
- **순수 전체화면 모드 (`Alt+Enter`)**: 타이틀 바와 테두리가 사라지는 완전한 전체화면 모드입니다. 마우스를 화면 상단/하단으로 가져가면 오토 하이드 컨트롤 바와 상단 바가 부드럽게 나타납니다.

### 8. 실시간 오디오/자막 트랙 전환 & 외부 자막 로드
- 재생 중 화면을 우클릭하여 원하는 오디오 트랙 및 자막 트랙을 실시간으로 변경하거나 자막을 끌 수 있습니다.
- `자막 열기...` 메뉴를 통해 외장 자막 파일(`.srt`, `.ass`, `.smi` 등)을 즉시 불러와 동기화할 수 있습니다.

### 9. 4개 국어 글로벌 다국어 지원 (i18n)
- **한국어(ko), English(en), 日本語(ja), 简体中文(zh)** 4개 언어를 완벽하게 지원합니다.
- 우클릭 메뉴의 `언어 (Language)` 항목에서 클릭 한 번으로 즉시 UI 언어를 전환할 수 있으며, 설정은 영구 보존됩니다.

## 🛠️ 요구 사항 (Prerequisites)

이 프로그램을 실행하기 위해서는 다음 환경이 시스템에 준비되어 있어야 합니다.

1. **Python 3.10 이상** (Windows 권장)
2. **필수 Python 패키지**:
   ```bash
   pip install -r requirements.txt
   ```
   - `PySide6`: 현대적인 Qt GUI 툴킷
   - `python-mpv`: libmpv 파이썬 바인딩
3. **FFmpeg & ffprobe**:
   - 시스템 환경 변수 `PATH`에 등록되어 있어야 합니다. (`ffmpeg -version` 확인)
   - 다운로드: [https://ffmpeg.org/download.html](https://ffmpeg.org/download.html) 또는 [Gyan.dev FFmpeg Builds](https://www.gyan.dev/ffmpeg/builds/)
4. **libmpv 동적 라이브러리 (`libmpv-2.dll`)**:
   - Windows 환경의 경우 프로젝트 루트 디렉터리에 `libmpv-2.dll` 파일이 포함되어 있어야 합니다. (누락 시 `python download_mpv.py` 실행으로 자동 다운로드 가능)

## 💡 사용 방법 안내

### 1. 파일 열기
- 비디오 파일(`.mkv`, `.mp4`, `.avi`, `.webm` 등)을 메인 윈도우 창으로 **드래그 앤 드롭**하거나, 좌측 하단의 파일 열기 버튼(또는 `Ctrl+O`)을 누릅니다.

### 2. 구간 지정 및 자르기
1. 타임라인 슬라이더나 탐색 버튼(`←/→`, `D/F`, `Space`)을 사용해 시작할 지점으로 이동한 뒤 **`[`** 키(또는 `[` 아이콘 버튼)를 누릅니다.
2. 끝 지점으로 이동한 뒤 **`]`** 키(또는 `]` 아이콘 버튼)를 누르면 구간이 확정되어 타임라인과 우측 하단 목록에 등록됩니다.
3. 여러 구간이 필요하다면 위 과정을 반복하여 원하는 만큼 구간을 누적 등록합니다.
4. **출력 방식 선택**:
   - **여러 구간을 하나로 합쳐서 저장**: `다중 구간 병합` 체크박스를 **체크**합니다. (`{영상명}_merged.mkv`)
   - **각 구간을 개별 클립으로 분할 저장**: `다중 구간 병합` 체크박스를 **해제**합니다. (`{영상명}_part1.mkv`, `{영상명}_part2.mkv` ...)
5. **`[내보내기]`** 버튼을 클릭하면 실시간 프로그레스 바가 표시되며 원본 화질 그대로 초고속 저장됩니다.

### 3. 다중 파일 병합 (여러 동영상 이어붙이기)
1. 병합하려는 여러 영상 파일을 탐색기에서 선택한 후 우측 **'다중 파일 병합 대기열'** 목록에 끌어다 놓습니다.
2. 목록에서 영상을 클릭하여 순서를 위/아래 버튼으로 조정할 수 있으며, 더블 클릭 시 해당 영상을 즉시 재생해 볼 수 있습니다.
3. 하단의 버튼이 자동으로 **`[병합 시작]`**으로 변경됩니다. 버튼을 누르고 저장 위치를 선택하면 파일들이 순서대로 하나로 결합됩니다.

### 4. 특정 오디오 / 자막 트랙만 분리 추출
1. 좌측 하단의 '트랙, 챕터와 태그' 목록에서 원하는 트랙의 체크박스를 설정합니다.
2. 불필요한 다국어 음성이나 자막을 제외한 상태로 **`[내보내기]`**를 누르면 해당 트랙들만 포함된 가벼운 영상 파일이 생성됩니다.
3. 자막 트랙을 우클릭하거나 선택하여 단독 텍스트 자막(`.srt`, `.ass` 등)으로 추출할 수도 있습니다.

### 5. 고화질 스크린샷 캡처
- 영상 시청 중 소장하고 싶은 장면에서 **`F8`** 키 또는 선택 초기화 버튼 우측의 **스크린샷 카메라 아이콘**을 클릭합니다.
- 자막이 표시되고 있더라도 자막 없는 순수 영상 원본 프레임이 저장되며, 클립보드에 자동 복사되므로 그림판이나 메신저에 바로 붙여넣을 수 있습니다.

## 📌 기술적 유의 사항

- **I-Frame(키프레임) 기반 무손실 스트림 복사의 특성**:
  본 프로그램은 원본 화질을 100% 보존하고 수 초 만에 작업을 끝내기 위해 재인코딩을 거치지 않는 `-c copy` 방식을 채택합니다. 따라서 동영상 압축 코덱 구조상 자르기 시작 지점이 가장 가까운 **키프레임(Keyframe / I-Frame)** 위치로 정렬되어 저장될 수 있습니다. 1프레임 단위로 미세하게 앞뒤를 확인하시려면 `D` / `F` 단축키를 활용해 주시기 바랍니다.
